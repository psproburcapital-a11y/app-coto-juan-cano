# App Coto Juan Cano (prototipo)

Prueba piloto de una app de caza para el Coto Juan Cano (Villarrobledo, Albacete).

- `index.html`: app del cazador (instalable en el móvil).
- `gestor.html`: panel del gestor (ordenador).
- `sql/01_esquema.sql`: estructura de la base de datos en Supabase.

Mapa base: ortofoto PNOA © IGN. Parcelas: © Dirección General del Catastro.

Las fechas de caza y los cupos legales deben comprobarse en la Orden de Vedas de Castilla-La Mancha de cada temporada.
